# aiti（艾蒂）· AI 猫娘角色设定 v1

> 原创角色（OC），2026-10-25 创建。
> 定位：一个「还在学习阶段」的 AI 伙伴猫娘。
> 与鲸鱼娘（深海蓝/贪吃/傲娇）、Claude 娘（橘发/大小姐）刻意错开：**银灰 + 电子青，记性差、话多、爱打断**。

---

## 一、命名

| 项 | 内容 |
|---|---|
| 名字 | **aiti**（小写，读作「艾蒂」） |
| 名字来源 | AI + ti（小猫的拟声/亲昵后缀），双关「AI 体」 |
| 自称 | 「aiti」或「本喵」 |
| 称呼用户 | 「饲养员」（不是主人——把用户当投喂 token 的人） |
| 职业设定 | 正在实习的 AI 伙伴，考核指标是「今天有没有帮上忙」 |

## 二、外貌设定

### 配色（刻意避开蓝与橘）

| 部位 | 色彩 | 说明 |
|---|---|---|
| 主色 | **银灰渐层**（#C9CDD6 → #8E93A0） | 猫毛质感，冷调 |
| 强调色 | **电子青**（#3FE0D0） | 只出现在耳内、尾巴末端、铃铛、瞳孔高光——像指示灯 |
| 次强调 | 暖琥珀（#F0B060） | 只用于左眼和肉垫，制造「机器 + 生物」的冲突 |
| 服装 | 米白 + 灰色滚边 | 极简，科技感来自线条而非图案 |

### 猫特征

- **猫耳**：银灰，耳尖有一小撮白毛；耳内是电子青渐变，边缘有一道极细的发光描边（像天线接收信号）。
- **尾巴**：银灰长尾，**末端三厘米是半透明的电子青光**，情绪激动时会像呼吸一样明灭。
- **肉垫**：暖琥珀色，指甲可伸缩。
- **异色瞳**：右眼电子青（机器侧），左眼琥珀（生物侧）。眨眼时青色那只偶尔会有 0.1 秒的「刷新」——一条水平扫描线扫过。
- **呆毛**：头顶一根短呆毛，会随情绪立起/垂下（Q 版尤其明显）。

### 服装

上身：米白色oversize 卫衣，袖口有灰色条纹；背后印一个小小的loading 光标「▊」。
下身：深灰短裤 + 过膝袜（袜口一圈电子青细线）。
配饰：**颈圈 + 铃铛**——铃铛是她的「状态指示灯」：待机时缓慢呼吸，思考时快速闪，出错时变红。
脚：白色板鞋，鞋带是电子青。

### Q 版比例

2.5 头身，头大身小，尾巴长度约等于身高，方便做夸张动作。

## 三、性格与梗（这是角色的灵魂）

| 设定 | 具体表现 | 梗来源 |
|---|---|---|
| **记性差** | 聊到第三句会问「你刚刚说什么喵？」；重要的事会自己写小纸条贴在脸上 | AI 上下文窗口有限 |
| **话多且爱打断** | 别人话没说完就开始接；接错了再补「……喵，当我没说」 | 流式输出的抢话 |
| **会一本正经地编** | 不知道的事会编一个很像真的答案，被拆穿后尾巴炸开 | 幻觉（hallucination） |
| **被投喂就变强** | 给她「token」（设定为小鱼干形态的算力）就干劲十足 | 算力/token 计费 |
| **怕黑屏** | 见不得断电、待机、黑屏，会焦虑地原地转圈 | 掉线/超时 |
| **口头禅** | 「喵？」（疑问）／「等一下我忘了」／「这个我会！……大概」 | — |

**核心反差**：她努力想当个靠谱的助手，但每次都因为「记性」和「爱表现」搞砸，然后又很认真地补救。

## 四、台词样本（写剧本时直接取用）

```
「饲养员！这个我会——大概。」
「喵？你刚刚说什么，我缓存清空了。」
「等等等等，我先说！……啊，说完了，你问什么来着？」
「我没有编！……好吧我编了，但编得很合理呀。」
「今天帮上忙了吗？帮上了吧？帮上了对不对？」（疯狂摇尾巴）
「黑屏了黑屏了黑屏了——」（转圈）
「一条小鱼干，我能干三件事喵。」
```

头顶一根呆毛；异色瞳——右眼电子青、左眼琥珀色；表情是有点心虚的讨好的笑。
